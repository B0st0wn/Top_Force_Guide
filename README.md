# Top Force Guide

Static site for GitHub Pages.

## GitHub Pages

Publish from the repository root (or copy these files into the folder configured as the Pages source). `index.html` is the site entry point. All local links are relative so the site works both at a user site and under a project path such as `https://username.github.io/repository/`.

Files:
- `index.html` — Combat Guide
- `vs-battle.html` — VS Battle Planner
- `style.css` — shared styles
- `.nojekyll` — disables Jekyll processing



- VS planner automatically detects the current VS day from the 02:00 UTC server reset and shows the next reset in the viewer's local time.
